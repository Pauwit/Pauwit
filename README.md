# Hi, I'm Paul

I'm a final-year engineering student at EPITA in Paris (Data Science & AI). I like machine learning, deep learning, and computer vision, mostly in Python and C++.

Right now I'm doing my end-of-studies project at Cloud Temple, working on sovereign AI infrastructure. I'm looking for a 6-month internship in ML / computer vision starting February 2027.

From September 2025 to January 2026 I interned at Institut Langevin (CNRS), where I trained the segmentation models behind EyeFlow, a retinal imaging tool that is now used daily at the Quinze-Vingts hospital in Paris.

## Things I've built

- [EyeSegmentation](https://github.com/Pauwit/EyeSegmentation): the models from that internship, for retinal Doppler holography images. They segment the optic disc and classify the eye side.
- [Neural network from scratch](https://github.com/Pauwit/cpp-neural-net): C++, no ML libraries, trained on MNIST. I wanted to actually understand backprop.
- [StockAI](https://github.com/Pauwit/stockai): finds empty shelf space in a photo, forecasts demand, and lets an LLM agent decide whether to restock.
- [DealBoard](https://github.com/Pauwit/Gemini-3-Hackathon-Paris): an AI copilot for Google Workspace, built in six hours at the Gemini 3 hackathon.
- [Tanks](https://github.com/Pauwit/tanks): a multiplayer tank game, written entirely by hand with no AI help.
- A Tiger compiler and a POSIX shell, both for school and private.

I also like hackathons and algorithm contests. Most recently my teammate and I won the Thales Battle Dev 2026, ranking 1st of 421 teams.

More on my [website](https://paulwitkowski.com) and on [LinkedIn](https://www.linkedin.com/in/paul-stanislas-witkowski).
